AI Image Generation Web App 🖼️🤖
A simple web app that uses the Replicate API to generate images from text prompts. Enter a prompt, generate an image, and download it! 🎨

Features 🚀
Generate Images: Create stunning images from text prompts.

Download Images: Download your generated image to your device. 💾

Customizable Models: Choose different AI models for image generation. 🔧

Tech Stack 🛠️
Backend: Python (Flask)

Frontend: HTML, CSS

API: Replicate API

Environment: Python 3.x, virtual environment
